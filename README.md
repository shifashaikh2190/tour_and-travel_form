# Tour and Travel Form

A simple HTML form for collecting tour and travel booking details.

## Features

* Full Name
* Email Address
* Gender Selection
* Destination Dropdown
* Screenshot Upload
* Phone Number
* Submit and Reset Buttons

## Technologies Used

* HTML5

## Project Structure

```text
tour_and_travel_form/
├── form.html
└── README.md
```

## Run Locally

Open `form.html` in any web browser to view and use the form.
